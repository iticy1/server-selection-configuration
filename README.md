## 先回答四个问题，配置单会自己浮出来

这四件事没想清楚，任何配置推荐都是猜的：网站跑什么程序、要支撑多少访问、数据要存多少、业务停多久算事故。

第一个问题决定性能基线。纯静态展示站和跑 WordPress 的站，对 CPU、内存的要求差一个档次；论坛、商城、流媒体又是另一回事。程序越重、动态请求越多，CPU 和内存越不能省。

第二个问题要拆成三个数字：注册用户数、日常同时在线人数、每天峰值。只报「我们大概有几千用户」没法算配置，要让技术或业务把用户数换算成并发连接数——这两个不是一回事。

第三个问题最容易被低估。除了操作系统和程序本身，还要算数据库、日志、备份、用户上传的内容。按未来 1–3 年的增长估，再乘 1.5 左右的系数留给备份和迁移。一个现在只占 8GB 的站，日志和备份半年就能把 20GB 硬盘吃满。

第四个问题影响的是冗余方案，不是单纯配置高低。只有一台应用服务器时，RAID、快照、备份这些不能省；已经有两台以上做了负载均衡，单机就没必要堆到顶配。

## 共享、VPS、云服务器、独立服务器，先选对类型

类型选错，后面参数调得再细也白搭。预算紧、流量小的展示站用共享主机；要独立资源和独立 IP 选 VPS；流量波动大、要做推广活动的选云服务器；数据量大且有技术团队，再考虑独立服务器。

| 类型 | 资源与隔离 | 适合谁 | 参考月费（加元/月） |
| --- | --- | --- | --- |
| 共享主机 | 与其他站点共用 CPU、内存、带宽，通常共用 IP | 个人博客、文字站、展示型企业站 | 3–10 |
| VPS | 单台物理机划分，资源独立、独立 IP，需自己维护 | 图片视频多的站、产品多的电商、要控制权的团队 | 20–100 |
| 云服务器 | 云端集群，按需付费，高峰期可自动加资源 | 高速增长的站、高流量营销页、对速度要求高的电商 | 100 起 |
| 独立服务器 | 整台物理机，权限最大，维护责任也最大 | 成熟网站、存大量用户数据的企业 | 100 起 |
| 托管型 | 在以上类型上加软硬件配置、更新和技术支持 | 没有技术人员、对安全和性能要求高的站 | 10 起 |

表内价格来自加拿大服务商 2021 年的公开报价，用来看量级；国内厂商的实际价格差别不小，以官网为准。

几个容易踩的点：

共享主机便宜是有代价的。同一台机器上所有站点共用一个 IP，会带来国内用户访问不了的风险；同机器上其他站点跑满资源，你的站也会跟着变慢。

VPS 的「独立」只到虚拟化这一层，配置有上限，系统更新、安全补丁、环境搭建都要自己来。没有运维人手，这笔时间成本得提前算进去。

云服务器按量付费很灵活，代价是账单不固定。忘记关测试机、被爬虫刷流量，月底账单会教你做人。开好用量告警，比事后申诉有用。

独立服务器适合数据敏感、有明确合规要求的场景，「什么都能改」的另一面是「什么都要自己管」。

拆开说。

CPU 方面，流量不大、页面以静态为主的站，1–2 核够用；动态页面多、装了十几个插件的 WordPress，建议 2 核起；商城、论坛这类高并发场景，4 核以上更合适。

内存决定缓存能开多大，也直接影响打开速度。静态站和博客 1–2GB 能跑；WordPress、Joomla 这类 CMS 建议 2–4GB；电商、社区、流媒体 8GB 以上。有条件选 ECC 内存，能自动纠正错误，稳定性更好。

硬盘优先 SSD，读取速度对动态网站影响明显。容量按前面说的 1–3 年增长测算，别只按当前数据量买。系统和程序放 SSD，大量图片视频可以另配 HDD。

操作系统看技术栈：Linux 对 PHP 友好、更省内存；Windows Server 对 ASP.NET 支持好，但本身占内存多。团队熟悉哪个就用哪个，硬换系统省下的授权费，通常会以运维时间的形式还回去。

地区选目标用户所在的区域，物理距离越近，响应越快。用户分散在多地，就上 CDN，不要指望一台机器覆盖全国。

## 带宽要买多大：两种算法能差出十倍

日常以文字和图片为主的网站，2Mbps 起步通常够用；按峰值并发理论算出来的数字会大得多，因为那是不含 CDN 和压缩的上限值。

理论算法的典型例子：页面平均 2MB，峰值 200 人同时在线，要求 2 秒加载完，那么带宽需求约等于 2MB × 200 ÷ 2 秒 ≈ 200MB/s，换算过来 1.6Gbps 上下，实际选型时通常按 2Gbps 这种量级估。看着吓人，但它假设每个请求都直接打到源站、没有任何缓存。

实际经验值低得多：新站图片不多且做过压缩，2M 带宽就够；普通的文字站、图片站、论坛，5000 访问量可能都占不到 2M；视频和下载站另算，几百人同时在线就可能吃掉 10M 以上。

差距来自三件事：CDN 把大部分请求挡在源站之外，WebP 和 Gzip 把文件压小，浏览器缓存让回访用户几乎不产生流量。这三样做完，源站带宽需求往往只剩理论值的几分之一。

所以带宽不要一步买满。先买 2–5Mbps，开启 CDN 和压缩，跑一周看监控里的峰值和平均值，不够再升。云服务器按量计费在这里很好用：临时活动把带宽调上去，活动结束调回来。

## 还有一层常被忽略：Web 服务器软件选型

买多大配置之外，服务器上装什么 Web 软件同样影响性能。选错了，同样的硬件可能只跑出一半的吞吐。

| Web 服务器 | 核心优势 | 主要局限 | 典型场景 |
| --- | --- | --- | --- |
| Apache | 模块化扩展灵活，PHP 支持成熟，文档多 | 多进程模型吃内存，万级并发时性能下降 | 中小企业官网、WordPress |
| Nginx | 事件驱动，能处理 10 万级并发，反向代理效率高 | 动态内容依赖 FastCGI，配置语法偏复杂 | 高并发 API 网关、静态资源加速 |
| IIS | 图形界面好管，与 .NET、ASP.NET 深度整合 | 只能跑 Windows，开源插件生态弱 | 政府 OA、.NET 企业应用 |
| Lighttpd | 内存占用约 1MB，资源消耗极低 | 模块少，商业支持不足 | 嵌入式设备、轻量 CDN 节点 |
| Tomcat | 纯 Java 环境，热部署方便 | 静态文件处理差，默认线程池 200 并发 | Spring Boot 应用、JSP 商城 |

在一组 4 核 8G 环境的测试里，静态文件吞吐 Nginx 约 8.5 万 QPS，Apache 约 2.3 万，Lighttpd 约 7.1 万；PHP 动态请求 Apache + mod_php 延迟约 12ms，Nginx + PHP-FPM 约 9ms。这些数字来自特定测试环境和版本，别当成绝对值，但量级关系有参考价值。

按技术栈对应：

- WordPress 和其他 PHP 程序：Nginx + PHP-FPM，或者 Apache + mod_php。前者延迟略低，后者用 .htaccess 做配置更灵活。
- Java / Spring Boot：Nginx 放前面处理静态请求和反向代理，Tomcat 在后面跑应用，动静分离。
- ASP.NET：Windows Server + IIS，没有太多选择余地。
- 纯静态站或小项目：Nginx 就够；内存特别紧张的话可以看 Caddy，占用更低。

HTTPS 现在有免费证书（Let's Encrypt），别省这一步。上线后把缓存（Redis、Varnish）和防火墙也配起来，关掉用不到的端口，能挡掉相当一部分麻烦。

## 机房位置和备案，会影响你后面几年的体验

主要用户在中国大陆，就选大陆机房并完成 ICP 备案；主要用户在海外，选目标市场的机房，或者用 CDN 分发。这件事在买服务器之前就要定，买完再迁机房，数据迁移和重新备案都够折腾。

境外主机不用备案，这是不少人选它的原因。代价是跨境链路的延迟和稳定性波动，晚高峰尤其明显。现在备案流程比前几年简化了不少，主机服务商一般也会提供备案支持，如果用户基本都在境内，走备案流程通常比绕开更划算。

面向多个地区做内容站或外贸站，主机放在主要市场，再用 CDN 补其他区域，比在单个机房上纠结配置更有效。

## 常见问题

**1 核 2G 能跑 WordPress 吗？**
能跑，但插件装得多、流量上来之后会吃紧。2 核 4G 是更稳的起点，尤其是装了缓存插件、安全插件、页面构建器的情况下。

**2M 带宽能支持多少人同时访问？**
没有固定换算。同样是 2M 带宽，纯文字站能撑起几千日访问量，视频站几百人同时在线就吃紧。关键变量是页面大小、有没有开 CDN、用户能接受多长的加载时间。

**服务器一定要备案吗？**
用中国大陆机房需要 ICP 备案，用境外机房不需要。免备案的代价是跨境访问的延迟和稳定性，怎么选取决于用户在哪里。

**云服务器和 VPS 有什么区别？**
VPS 是从单台物理机划分出来的虚拟服务器，资源独立但有单机上限；云服务器是多台服务器组成的集群，其中一台出问题，其他机器会接管。前者便宜、可控，后者稳定性和扩展性更好。

**先买一个月还是一年？**
流量没跑出来之前，先按月或按量。拿到监控数据，再决定是否换成年付锁定成本。已经很确定长期要用的站，年付通常更划算。

## 按你的情况对号入座

个人博客或展示站，日访问几百：1–2 核、1–2GB 内存、20–50GB SSD、2Mbps 带宽，最低配云服务器或共享主机都行。

WordPress 企业站，装了十来个插件：2 核 4G 起步，50GB SSD，开 CDN 和缓存插件，带宽先买 2–5Mbps。

电商、社区或有促销峰值的站：4 核 8G 起，按量计费配合自动伸缩，带宽按峰值并发估算，别按日常流量买。
